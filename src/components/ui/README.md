# UI primitives

This folder holds the design-system primitives every page downstream composes
from. The design authority is the MagicPath **"Stanzy Design System"** project;
see issue #3 and `GLOSSARY.md`.

Light-mode only. All brand colour/typography/spacing/radius/shadow/motion
tokens live in `src/app/globals.css` under `@theme` / `:root` and semantic
aliases like `--color-text-muted`, `--color-surface`, `--color-danger` should
be preferred over raw brand hexes.

## Two kinds of files

| Kind | Who writes them | How to change |
|---|---|---|
| **Vendor** (shadcn/ui, 63 files) | Generated by `npx shadcn add` | Prefer re-running `shadcn add --overwrite` over hand edits; override behaviour in a wrapper if needed. Lint rules relax for these files (see `eslint.config.mjs`). |
| **Authored** wrappers | This repo | Edit freely. They're thin by design. |

## Authored wrappers

| File | Purpose | MagicPath mapping |
|---|---|---|
| `app-shell.tsx` | Page frame: nav slot, main, footer slot | Layout section |
| `nav.tsx` | Top navigation + `NavItem` with locale-aware `Link` and active underline | Navigation section |
| `footer.tsx` | Site footer with column slots and bottom row | Footer (generic) |
| `icon.tsx` | Lucide wrapper enforcing the design-md sizes (16/20/24/32) and the aria-hidden-by-default rule | Iconography section |

## Vendor primitives

Everything else in this folder was installed verbatim by
`npx shadcn@latest add --all` on the `base-nova` style. Themed through the
shadcn semantic CSS variables mapped to Stanzy tokens in `globals.css`:

- `--primary` → `--rouge` (CTAs)
- `--secondary` → `--navy-deep` (structural)
- `--destructive` → `--crimson` (distinct from primary)
- `--background` → `--off-white`
- `--muted` → `--ice-blue`
- `--ring` → `--rouge`

The sidebar block is navy-on-white for the admin dashboard.

## Showcase

Every primitive renders at **`/[locale]/design`** (noindex, env-gated on
production — see `NEXT_PUBLIC_ENABLE_DESIGN_SHOWCASE`). Review visual parity
against MagicPath there.

  every shadcn↔brand mapping).
- `tests/components/*.test.tsx` — authored wrappers only. Vendor files are
